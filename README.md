## Secure Configuration Guardian - Dashboard

Dashboard built with NextJS, for the Secure Configuration Guardian!

Startup instructions: 
1. Run the command `npm install` to install dependencies
2. Run the command `npm run build` to build the production bundle
3. Run the command `npm start` to start the production server
4. Voila

Development instructions:
1. Run `pnpm dev` or `npm run dev` (whichever you prefer) to start the development server
2. In `next.config.js`, uncomment the development-specific configuration
3. Run `npm run build` to verify the build works
4. Run `npm start` to test the production build locally
5. Voila
